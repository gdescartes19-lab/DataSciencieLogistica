# Logistics Intelligence · Análisis y predicción logística

Proyecto de portafolio de análisis de datos, estadística aplicada y simulación de operaciones logísticas.

## Abrir el proyecto

- **Informe interactivo:** abre `index.html` en el navegador, o visita la URL de GitHub Pages de este repositorio.
- **Libro de Excel:** abre `Logistics_Intelligence_Calculos_y_Dataset.xlsx`. También se puede descargar directamente desde el apartado «¿Cómo se construyó el análisis?» del informe.

No es necesario subir datos ni instalar dependencias para explorar el informe. Los estilos, scripts y la fotografía de portada están integrados en el archivo HTML.

## Contenido del libro de Excel

17 hojas: `00_Guia`, `01_Dashboard`, `02_Datos`, `03_Mensual`, `04_Regiones`, `05_KPI`, `06_Estadistica`, `07_Correlaciones`, `08_Pronosticos`, `09_Modelo_Tiempo`, `10_Modelo_Riesgo`, `11_Validacion`, `12_Flota`, `13_Capacidad`, `14_Simulacion`, `15_Auditoria` y `16_Frecuencias`.

## Publicar con GitHub Pages

1. Crea un **repositorio público** en GitHub.
2. **Descomprime el ZIP** y sube `index.html`, el `.xlsx` y `README.md` a la **raíz del repositorio**. No subas únicamente el ZIP: GitHub no lo descomprime automáticamente.
3. En **Settings → Pages**, selecciona **Deploy from a branch**; elige `main` y la carpeta `/ (root)`; guarda los cambios.
4. Una vez publicado, abre la dirección que GitHub muestre en Pages. El botón del informe descargará el Excel mediante una ruta relativa válida para GitHub Pages.

Los archivos funcionan como sitio estático: **sin backend, npm, base de datos remota ni servicios de pago**.

## Alcance, procedencia y limitaciones

Los **16.500 pedidos del informe son sintéticos y reproducibles**. No son registros reales de Olist, de una empresa de paquetería ni de un transportista. La fuente pública Olist se cita como referencia metodológica, **pero no se incorpora su dataset real**.

Los datos de flota y combustible también corresponden a **supuestos de simulación**. Las predicciones son ejercicios de demostración y su evaluación no constituye evidencia de rendimiento en una operación real.

**Privacidad del autor:** este repositorio publica la fotografía y los datos de contacto que aparecen en el HTML. Revisa esta información antes de compartir el repositorio públicamente.
